




# Customer Order Management System

Python Object-Oriented Programming Exam Project

## Features

- Regular and VIP customers
- Regular and VIP orders
- Unique customer and order IDs
- Unique item IDs within each order
- Automatic order price calculation
- VIP discounts
- Customer favorite items
- Gift management
- Multiple payment methods

## OOP Concepts

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstract Classes
- Interfaces

## Bonus

Animal hierarchy:
- Animal
- Pet
- Spider
- Cat
- Fish

```bash
python main.py
```
